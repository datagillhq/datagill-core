# Flag Audit Detail — Removed

This page and its associated API endpoints have been removed from scope entirely. DataGill is a business intelligence tool — for flag-level detail, users are linked directly to their source provider (e.g., LaunchDarkly) via `sourceUrl` in analytics responses.

This is not a "future" item. Do not implement any flag-level detail endpoints.

Flag-level analytics may be revisited only if a clear product requirement emerges. If that happens, start a new design doc from scratch rather than using this file.
